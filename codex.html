Qué es
Una red social para estudiantes: publicar dudas con código, seguir a gente, hablar en tiempo real y tener un espacio privado para cada centro. Fue mi proyecto final de DAW.
Qué hice yo
En un equipo de cuatro, hice la mayor parte de la API en Laravel (publicaciones, acceso con Google, búsqueda, centros y notificaciones) y el despliegue con Docker y GitHub Actions. También trabajé en la interfaz.
Un reto
Que las notificaciones lleguen al momento. La API en Laravel las publica en Redis y un servidor de Socket.io, aparte, las reparte a cada usuario conectado.
Estado
El código es público. La versión en línea está en preparación.
Tecnologías
React, Laravel, Socket.io, WebRTC, Redis, Docker
